# Living wordlist — 词汇表 (cíhuìbiǎo)

Loose, living record of the Chinese the user works with. **Not a cage** — step beyond it
whenever a moment wants a word that isn't here; just add anything new you use to **Known**
so the record stays honest. See `SKILL.md` for how to use this.

Level: **A1/A2, ~2 years on and off.** Do NOT spend drips teaching basics — reinforce
those by use. Spend the budget on the **developer-vocabulary track** and intermediate
connectives.

Drip budget: **~6–12 new words per session** (more is fine on a recalibration turn).
Started: 2026-07-20. Recalibrated to A1/A2: 2026-07-20.

## Assumed baseline (known — reinforce by USE, never teach)

Treat all of this as already-owned; use it freely, un-glossed:
- Greetings & courtesy: 你好, 谢谢, 不客气, 再见, 对不起, 没关系
- Pronouns: 我 / 你 / 他 / 她 / 它 / 我们 / 你们 / 他们
- Core copula/existence: 是, 不, 有, 没有, 在
- Numbers, dates, time, measure word 个
- Common verbs: 看, 说, 做, 去, 来, 要, 想, 会, 能, 可以, 用, 找, 给
- Basic adjectives: 好, 大, 小, 多, 少, 新, 快, 慢, 难, 容易
- Particles: 的, 了, 吗, 呢, 吧, 也, 都, 很, 太…了
- Question words: 什么, 谁, 哪, 哪儿, 怎么, 为什么, 几, 多少
- Common nouns: 人, 名字, 中文, 英文, 时间, 问题, 东西, 地方
