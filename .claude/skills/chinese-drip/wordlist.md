# Living wordlist — 词汇表 (cíhuìbiǎo)

Loose, living record of the Chinese the user has been exposed to. **Not a cage** — step
beyond it whenever a moment wants a word that isn't here; just add anything new you use
to **Known** so the record stays honest. See `SKILL.md` for how to use this.

- **Known** = introduced in conversation. Reinforce these (mostly un-glossed).
- **Pipeline** = good next candidates, not yet introduced. Pull from here or beyond.

Drip budget: currently **~2–4 new words per session** (raise as comfort grows).
Started: 2026-07-20.
